# ADC / DAC Testbench

Программа для отображения данных АЦП и управления испытательным стендом.
Версия 0.2 — работающий прототип интерфейса с восемью демонстрационными каналами.
Протокол прибора ещё не определён; кнопка подключения намеренно недоступна.

## Запуск в Windows

Для USB-Flash используйте **переносимую сборку**, описанную ниже.
Следующие команды предназначены для запуска исходников на компьютере разработки.

Запустите `start.cmd` двойным щелчком. При первом запуске создаётся `.venv`
и загружаются зависимости (нужен интернет). Используется установленный Python 3.12+
либо локальный Python из среды Codex. При необходимости установку можно выполнить
отдельно командой `powershell -ExecutionPolicy Bypass -File .\setup.ps1`.

## Что доступно

- Запуск и остановка восьми демонстрационных сигналов: 1000 отсчётов/с на канал.
- Список COM-портов обновляется каждые 1,5 секунды, выбранный порт сохраняется,
  пока он доступен. Подключать USB–COM можно после запуска программы.
  При раскрытом списке обновление откладывается до его закрытия. Порт пока не открывается.
- Восемь отдельных галочек CH1–CH8 управляют только видимостью кривых.
- Выбор скорости COM-порта от 1200 до 1000000 бод, включая 921600.
  Значение по умолчанию — 115200; доступность конкретной скорости зависит от адаптера.
- Включение каналов, окно 2–60 секунд, масштабирование мышью и автомасштаб по Y.
- Пауза графика: при запущенном демо приём в буфер продолжается.
- Текущее значение CH1, минимум, максимум, размах и СКО по отображаемому окну.
- Сохранение последних 60 секунд в CSV: источник `demo`, время, CH1–CH8,
  включая скрытые каналы.

Значения демонстрационных сигналов — коды 12-битного АЦП. Они не являются
показаниями прибора. Время демо задаётся номерами отсчётов; это не измерение
реальной частоты дискретизации. После остановки демо остаются доступными просмотр
и сохранение буфера. ЦАП появится после согласования команд прибора.

## Разработка

Стек: Python, PySide6, PyQtGraph, NumPy, pySerial.
Отступы — 4 пробела. В языках с блочными скобками используется стиль Allman.

Снимок интерфейса без прибора: `.venv\Scripts\python.exe app.py --preview`.
Файл `preview.png` и локальное окружение исключены из Git.

## Переносимая сборка для USB-Flash

Запустите `powershell -ExecutionPolicy Bypass -File .\build-portable.ps1`.
Скрипт использует pip из окружения разработки, загружает Python 3.8.10 x86
и фиксированные зависимости из `requirements-portable.txt`, создаёт папку
`portable` и архив `ADC-DAC-testbench-portable.zip`. После изменения исходников
сборку нужно повторить. Существующая папка `portable` предназначена только для
результатов сборки; пользовательские записи храните отдельно.

Распакуйте архив целиком на флешку и запустите **START.cmd**. Устанавливать
Python или библиотеки на целевом компьютере не нужно. Интернет при запуске не нужен.
Локальное окружение `.venv` на флешку копировать не нужно.

Целевые ОС: Windows 7 **SP1**, Windows 8/8.1 и Windows 10, 32/64 бит.
Используется PySide2 / Qt 5.15.2 вместо Qt 6, который Windows 7 не поддерживает.
Фактический запуск на каждой старой ОС пока не проверен. Для Windows 7 нужны
системные обновления Universal CRT; для прибора — драйвер USB–COM адаптера.
Подробности находятся в `PORTABLE.txt`. ARM и Windows RT не входят в целевые ОС.

Проверки: `.venv\Scripts\python.exe -m unittest discover -s tests -v`.
Те же проверки выполняются переносимым `portable\runtime\python.exe`.
