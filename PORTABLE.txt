ADC / DAC Testbench 0.3 — пробный обмен с прибором

Распакуйте архив целиком в папку на USB-Flash. Запускайте START.cmd.
Папку runtime и все файлы .py необходимо сохранять рядом с START.cmd.
Python, Qt, NumPy и pySerial входят в комплект; установка и интернет не нужны.
Запуск не требует прав администратора. Все библиотеки загружаются из этой папки.

Целевые системы: Windows 7 SP1, Windows 8/8.1 и Windows 10, x86/x64.
В комплекте Python 3.8.10 x86, Qt 5.15.2 / PySide2 5.15.2.1.
Проверка на каждой из старых ОС ещё необходима: сборка проверена только на
компьютере разработки. На Windows 7 нужны SP1 и системные обновления Universal
CRT (KB2999226 и его требования). На чистой системе без них запуск может
потребовать установки обновлений. Драйвер конкретного USB–COM адаптера должен
быть установлен на компьютере. Windows RT и ARM не входят в целевую конфигурацию.

Первый обмен
1. Выберите COM-порт, оставьте 9600 бод (8N1) и нажмите «Подключить прибор».
2. Журнал TX/RX постоянно виден внизу окна. На вкладке «Протокол» нажмите «Версия ПО · 5».
3. Если нет ответа, попробуйте второй вариант CRC запроса. В ответах программа
   сама проверяет сырой CRC и ASCII HEX. Сумма пока предполагается по CMD + DATA.
4. Для команд 3 и 5 переключатель «Номера команд в HEX» не меняет посылку.
   Разница появляется у команды 25: без галочки передаётся код 0x19, с ней 0x25.
5. Нажмите «Текущий уровень · 25». Если ответ корректен, появится точка CH1.
6. Для графика включите «Опрос уровня каждые 200 мс». При тайм-ауте или отказе
   прибора опрос выключается. Подключение само по себе не отправляет команд.
7. После теста отключите прибор. Исходный обмен находится в captures\exchange_*.jsonl
   рядом с программой (путь также показан в окне журнала). Если папка недоступна
   для записи, при подключении предлагается выбрать путь сохранения.

Журнал сохраняет исходные порции байтов RX/TX в HEX, время и настройки; это
не обязательно границы пакетов. Все данные записываются до проверки CRC.
В окне видны последние 500 строк; полный обмен находится в файле.
Высота журнала регулируется разделителем. Очистка экрана не очищает файл.
В демо журнал также заполняется: строки отмечены [ДЕМО] и не записываются в файл
обмена с прибором. Настоящие TX/RX отмечены [ПРИБОР].

CH1 показывает средневыпрямленный уровень по команде 25, а не сырые отсчёты АЦП.
CH2–CH8 отключены как резерв. На графике и в статистике — коды, в CSV также мВ
(код * 0.6105). Обновление списка портов каждые 1,5 с работает до подключения;
во время соединения порт и скорость фиксированы. Настройки порта на ПК
не меняют скорость прошивки. Команды перезапуска, ДК и записи настроек не посылаются.
Демо остаётся доступным после отключения прибора, данные источников не смешиваются.
