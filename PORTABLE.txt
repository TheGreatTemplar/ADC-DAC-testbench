ADC / DAC Testbench 0.5 — тестовая и рабочая v0.18

Распакуйте архив целиком в папку на USB-Flash. Запускайте START.cmd.
Папку runtime и все файлы .py необходимо сохранять рядом с START.cmd.
Python, Qt, NumPy и pySerial входят в комплект; установка и интернет не нужны.
Запуск не требует прав администратора. Все библиотеки загружаются из этой папки.

Целевые системы: Windows 7 SP1, Windows 8/8.1 и Windows 10, x86/x64.
В комплекте Python 3.8.10 x86, Qt 5.15.2 / PySide2 5.15.2.1.
Проверка на каждой из старых ОС ещё необходима: сборка проверена только на
компьютере разработки. На Windows 7 нужны SP1 и системные обновления Universal
CRT (KB2999226 и его требования). На чистой системе без них запуск может
потребовать установки обновлений. Драйвер конкретного USB–COM адаптера должен
быть установлен на компьютере. Windows RT и ARM не входят в целевую конфигурацию.

Первый обмен
Для Perimetr_v.0.18.hex: выберите «Рабочая v0.18», 19200 бод, 8N1.
После подключения автоматически читаются версия, ступень усиления и сигнал / порог
каждые 200 мс. Сигнал и тонкие линии ±порога показаны в единицах алгоритма.
Порог возврата доступен дополнительно через ST-Link/SWD с проверкой профиля v0.18.
Сырые CH1–CH3 и напряжение батареи рабочая прошивка не передаёт.
CSV: source, time_s, processed_signal, trigger_threshold, device_state.
На вкладке «Протокол» восемь кнопок усиления 1–8, активна одна.
Нажатие записывает ступень с автоматической проверкой чтением. Во время опроса
кнопки доступны: последняя выбранная ступень ожидает завершения текущего запроса.
Подключение не изменяет усиление само по себе.
Номера команд DEC и CRC из двух HEX-символов фиксированы по реализации v0.18.
Управление усилением в тестовой прошивке отключено. Рабочий профиль ещё требует
проверки реального UART-обмена с прибором. Программа сама не прошивает прибор.

Для testbench_1.hex (STM32L151C6T6A): выберите «Тестовая · АЦП A0–A2»,
19200 бод, 8N1 и подключите порт. Данные идут автоматически, без CRC и запросов.
CH1–CH3 = A0–A2; CSV сохраняет три кода АЦП без пересчёта в мВ.
CH1 / A0 — контроль целостности КЧЭ; CH2 / A1 — обработка тревоги;
CH3 / A2 — контроль питания (батареи).
Шкала CH2 в мВ: код × 3300 / 4095 (опора 3,3 В); коды АЦП остаются слева.
Шкала CH3 в В: код × 3,3 / 4095 × 64,2 / 42,2 (после замены резистора).
Делитель: 22 кОм от питания до входа повторителя, 42,2 кОм от этого входа до PA8=0.
Прежние журналы до замены резистора относятся к делителю 10,2 / 42,2 кОм.
Галочка «Фильтр CH3»: массив 256 отсчётов, отбрасывание по 25 крайних значений
с каждой стороны, среднее оставшихся 206. Первый результат примерно через 4,5 с.
Галочка переключает график, текущие вольты и статистику CH3. CSV сохраняет
исходные коды и поля a2_trimmed256_code, battery_trimmed256_V независимо от галочки.
При разрыве приёма более 2 с начинается новый массив; суточное расписание в прибор
не добавляется. Фильтр не исправляет ошибку опоры или ограничение выхода ОУ.
Адаптивные пороги: чтение автоматически запускается при подключении потока АЦП.
На графике тонкие сплошные линии — ±срабатывание, пунктирные — ±возврат;
их отдельная правая шкала — внутренние единицы обработки, не коды сырого АЦП.
На вкладке «Протокол» галочка «Пороги через ST-Link / SWD» отключает чтение.
Нужны отдельные драйвер ST-Link и STM32 ST-LINK Utility на этом компьютере;
они не входят в переносимую сборку. Закройте другие программы ST-Link.
Пороги читаются из ОЗУ в HOTPLUG, без остановки/сброса и записи прошивки.
Значения порогов — внутренние единицы алгоритма, не мВ сырого CH2.
После обновления исходников переносимую сборку нужно пересобрать.

Для командного протокола 0.0:
1. Выберите формат «Протокол 0.0», COM-порт, 9600 бод (8N1) и нажмите «Подключить прибор».
2. Журнал TX/RX постоянно виден внизу окна. На вкладке «Протокол» нажмите «Версия ПО · 5».
3. Если нет ответа, попробуйте второй вариант CRC запроса. В ответах программа
   сама проверяет сырой CRC и ASCII HEX. Сумма пока предполагается по CMD + DATA.
4. Для команд 3 и 5 переключатель «Номера команд в HEX» не меняет посылку.
   Разница появляется у команды 25: без галочки передаётся код 0x19, с ней 0x25.
5. Нажмите «Текущий уровень · 25». Если ответ корректен, появится точка CH1.
6. Для графика включите «Опрос уровня каждые 200 мс». При тайм-ауте или отказе
   прибора опрос выключается. Подключение само по себе не отправляет команд.
7. После теста отключите прибор. Исходный обмен находится в captures\exchange_*.jsonl
   рядом с программой (путь также показан в окне журнала). Если папка недоступна
   для записи, при подключении предлагается выбрать путь сохранения.

Журнал сохраняет исходные порции байтов RX/TX в HEX, время и настройки; это
не обязательно границы пакетов. Все данные записываются до проверки CRC.
В окне видны последние 500 строк; полный обмен находится в файле.
Высота журнала регулируется разделителем. Очистка экрана не очищает файл.
В демо журнал также заполняется: строки отмечены [ДЕМО] и не записываются в файл
обмена с прибором. Настоящие TX/RX отмечены [ПРИБОР].

В режиме протокола 0.0 CH1 показывает средневыпрямленный уровень по команде 25,
а не сырые отсчёты АЦП. CH2–CH8 отключены как резерв. На графике и в статистике — коды, в CSV также мВ
(код * 0.6105). Обновление списка портов каждые 1,5 с работает до подключения;
во время соединения порт и скорость фиксированы. Настройки порта на ПК
не меняют скорость прошивки. Команды перезапуска и ДК не посылаются.
Запись усиления выполняется нажатием кнопки 1–8 в профиле v0.18.
Демо остаётся доступным после отключения прибора, данные источников не смешиваются.
